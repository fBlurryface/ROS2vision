# ros2vision_interfaces

Shared ROS 2 message definitions for ROS2vision.

The current interface is [msg/Target.msg](msg/Target.msg), produced by the recognition detector and consumed by the UNO follower. Service and action directories are reserved; no service or action definitions are implemented.
